# Employee Attrition: Multi-Output Neural Network

A branched Keras neural network that predicts two things for each employee at once: **whether they are likely to leave** and **which department fits them best**. It uses a shared hidden layer with a separate output head for each prediction.

**Notebook:** `M19_Starter_Code/attrition.ipynb`

**Tools:** Python, pandas, scikit-learn, TensorFlow/Keras

*Coursework from the OSU AI Bootcamp.*
